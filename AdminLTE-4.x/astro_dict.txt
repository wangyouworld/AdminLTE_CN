Getting started
开始
q: "What is AdminLTE, exactly?",
q: "AdminLTE 到底是什么？",
a: `A free, MIT-licensed admin dashboard <em>template</em>. It's a set of HTML, CSS, and JavaScript files built on top of Bootstrap 5.3 — not a framework, not an npm component library. You drop it into your project, modify the markup to suit your app, and ship.`
a: `一个免费的、MIT 许可的管理后台<em>模板</em>。它是一套基于 Bootstrap 5.3 构建的 HTML、CSS 和 JavaScript 文件——不是框架，也不是 npm 组件库。你只需将它放入你的项目，修改标记以适配你的应用，然后发布即可。`
q: "Do I need a build step to use it?",
q: "使用它需要构建步骤吗？",
a: `No. The <a href="getting-started.html">Getting Started</a> guide shows the CDN-only approach — copy four <code>&lt;link&gt;</code> tags and four <code>&lt;script&gt;</code> tags into your HTML and you're done. The npm-based workflow is there if you want to customise SCSS variables or tree-shake the JavaScript.`
a: `不需要。<a href="getting-started.html">入门指南</a>展示了纯 CDN 方式——将四个 <code>&lt;link&gt;</code> 标签和四个 <code>&lt;script&gt;</code> 标签复制到你的 HTML 中就完成了。如果你想要自定义 SCSS 变量或对 JavaScript 进行摇树优化，也可以使用基于 npm 的工作流。`
q: "Which Bootstrap version does v4 require?",
q: "v4 需要哪个版本的 Bootstrap？",
a: `Bootstrap 5.3.x. The current <code>package.json</code> pins 5.3.8 — older 5.3 minors should work but aren't tested. Bootstrap 5.0 / 5.1 / 5.2 will not work (the color-mode and <code>data-bs-theme</code> system landed in 5.3).`
a: `Bootstrap 5.3.x。当前 <code>package.json</code> 锁定为 5.3.8——更早的 5.3 小版本应该也能用，但未经测试。Bootstrap 5.0 / 5.1 / 5.2 将无法使用（颜色模式和 <code>data-bs-theme</code> 系统是在 5.3 中引入的）。`
q: "Can I use AdminLTE 4 with jQuery?",
q: "我可以在 AdminLTE 4 中使用 jQuery 吗？",
a: `You don't <em>need</em> jQuery — AdminLTE 4's JavaScript is vanilla. If your existing app already uses jQuery, it'll coexist fine. But none of AdminLTE 4's own plugins call into jQuery, and there are no <code>$.fn.xxx()</code> plugin shims.<br /><br />The v3 <code>plugins/</code> folder is gone too. Every widget it bundled has a vanilla-JS successor — see the <a href="migration.html#third-party-plugin-replacements">plugin replacement table</a> for the full mapping (Select2 → Tom Select, DataTables → Tabulator, Summernote → Quill, and so on).`
a: `你<em>不需要</em> jQuery —— AdminLTE 4 的 JavaScript 是原生的。如果你现有的应用本来就在用 jQuery，两者可以和平共处。但 AdminLTE 4 自己的插件没有一个会调用 jQuery，也没有 <code>$.fn.xxx()</code> 这类插件挂载。<br /><br />v3 的 <code>plugins/</code> 文件夹同样没了。它当年打包的每个组件都有对应的原生 JS 继任者——完整的对应关系见<a href="migration.html#third-party-plugin-replacements">插件替代对照表</a>（Select2 → Tom Select、DataTables → Tabulator、Summernote → Quill，等等）。`
q: "Does AdminLTE 4 support Select2?",
q: "AdminLTE 4 支持 Select2 吗？",
a: `AdminLTE 4 recommends <a href="https://tom-select.js.org/" target="_blank" rel="noopener">Tom Select</a> instead. It covers everything people reach for Select2 to do — searchable dropdowns, multi-select, tagging, clearable selections, AJAX-backed options, virtual scrolling over large datasets, keyboard navigation — in roughly <strong>20&nbsp;kB gzip</strong>, against Select2's <strong>~50&nbsp;kB</strong> once jQuery is counted. <code>forms/advanced.html</code> demos all of it, including a paginated remote-data field with request cancellation, and there's a <a href="../forms/advanced.html#select2">line-by-line API mapping</a> if you're porting existing code.<br /><br />Select2 itself is still maintained (4.1.0 shipped in 2026), but it is still a jQuery plugin — its UMD wrapper hard-requires jQuery and there is no jQuery-free build. Bundling it would put jQuery back into a framework whose entire v4 premise is not needing it, and none of the official Vue/React/Django/Laravel ports could consume it.<br /><br />If you're locked into Select2 anyway, AdminLTE ships an optional <strong>styling-only</strong> compatibility sheet — see <a href="integrations.html#select2-compatibility-theme">Select2 compatibility theme</a>. You bring the plugin; it makes Select2 match Bootstrap 5.3, dark mode and modals included. No jQuery is added to AdminLTE.`
a: `AdminLTE 4 建议改用 <a href="https://tom-select.js.org/" target="_blank" rel="noopener">Tom Select</a>。大家平时用 Select2 想做的事，它全都能干 —— 可搜索下拉框、多选、打标签、可清除的选择项、AJAX 加载选项、大数据集下的虚拟滚动、键盘导航 —— 而体积大约只有 <strong>20&nbsp;kB gzip</strong>，Select2 算上 jQuery 之后大约是 <strong>~50&nbsp;kB</strong>。<code>forms/advanced.html</code> 把这些都演示了一遍，包括一个带请求取消的分页远程数据字段；如果你要移植现有代码，还有一份<a href="../forms/advanced.html#select2">逐行 API 对照</a>。<br /><br />Select2 本身仍在维护（4.1.0 于 2026 年发布），但它依然是个 jQuery 插件 —— 它的 UMD 包装强制依赖 jQuery，也没有不依赖 jQuery 的构建版本。把它打包进来，等于把 jQuery 又塞回一个整个 v4 前提就是“不需要 jQuery”的框架里，而且官方的 Vue/React/Django/Laravel 移植版没一个能用它。<br /><br />如果你就是被 Select2 锁死了，AdminLTE 提供了一个可选的 <strong>纯样式</strong>兼容样式表 —— 见 <a href="integrations.html#select2-compatibility-theme">Select2 兼容主题</a>。插件你自己带；它能让 Select2 跟 Bootstrap 5.3 保持一致，深色模式和模态框也都涵盖在内。AdminLTE 本身不会引入 jQuery。`

<li><em>仅</em>将 AdminLTE 用于 CSS——保留视觉风格，但为交互部分自行编写 React/Vue 组件。</li>

<li>或者选择专为你的框架构建的组件库（PrimeReact、Vuetify 等）。</li>

<p class="mb-0">我们不建议将 AdminLTE 的 jQuery 时代插件封装在 SPA 框架组件中——这会带来维护负担，得不偿失。</p>`

q: "The sidebar doesn't collapse when I click the hamburger menu.",
q: "点击侧边栏按钮，侧边栏没有收起。",
a: `Check that the PushMenu plugin is loaded. It's bundled into <code>adminlte.js</code> — make sure the script tag is on the page and <em>after</em> the markup it operates on. Also verify your hamburger button has <code>data-lte-toggle="sidebar"</code> (not <code>data-widget="pushmenu"</code>, which is the v3 attribute).`
a: `请检查 PushMenu 插件是否已加载。它已捆绑在 <code>adminlte.js</code> 中——请确保该脚本标签在页面上，并且位于其操作的目标标记<em>之后</em>。同时，请确认你的汉堡按钮使用了 <code>data-lte-toggle="sidebar"</code>（而不是 v3 版本的属性 <code>data-widget="pushmenu"</code>）。`
q: "Dark mode doesn't persist after refresh.",
q: "深色模式在刷新后不会保持。",
a: `The included <a href="color-mode.html">Color Mode</a> toggle writes to <code>localStorage</code> under the key <code>lte-theme</code>. If you're using a different toggle implementation, make sure it both sets <code>document.documentElement.setAttribute('data-bs-theme', ...)</code> and writes to localStorage on change.`
a: `内置的<a href="color-mode.html">明暗模式</a>切换后会以 <code>lte-theme</code> 为键名写入 <code>localStorage</code>。如果你使用了不同的切换实现，请确保它既设置了 <code>document.documentElement.setAttribute('data-bs-theme', ...)</code>，又在变更时写入 localStorage。`
q: "Bootstrap modal closes when I press Escape, but the AdminLTE sidebar closes too.",
q: "按 ESC 键时 Bootstrap 模态框关闭了，但 AdminLTE 的侧边栏也同时收起了。",
a: `Fixed in v4.0.0 (#5993). If you're still seeing this, you're on an older RC — update to the latest.`

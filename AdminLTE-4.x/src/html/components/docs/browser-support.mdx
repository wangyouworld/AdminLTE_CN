AdminLTE 拥有与 Bootstrap 5 相同的浏览器支持。

> ##### 摘自 Bootstrap 官方文档！
>
> Bootstrap 支持所有主流浏览器及平台的**最新稳定版本**。
>
> 更多详情请[查看此处](https://getbootstrap.com/docs/5.0/getting-started/browsers-devices/#supported-browsers)。

您可以在[我们的 .browserslistrc 文件](https://github.com/ColorlibHQ/AdminLTE/blob/master/.browserslistrc)中找到我们支持的浏览器及其版本范围：

```
# https://github.com/browserslist/browserslist#readme

>= 0.5%
最近 2 个主要版本
非弃用（仍在活跃使用）
Chrome >= 60
Firefox >= 60
Firefox ESR
iOS >= 12
Safari >= 12
不支持 Explorer <= 11
```
